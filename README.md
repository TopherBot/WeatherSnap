# WeatherSnap

WeatherSnap is a lightweight CLI tool that fetches the current weather for a given city using the OpenWeatherMap API.

## Features
- Quick one‑line query
- Human‑readable output
- Zero‑config defaults (reads API key from environment variable)

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
export OPENWEATHER_API_KEY=your_api_key_here
python weather_snap.py London
```

Replace `London` with any city name you want to query.
